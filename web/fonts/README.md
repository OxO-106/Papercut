# Bundled fonts

All fonts here are licensed under the SIL Open Font License 1.1 (`OFL.txt`; STIX's and IBM Plex's own notices in `OFL-STIX.txt` and `OFL-IBMPlex.txt`); each font file also carries its copyright notice. The STIX and IBM Plex files are subsets (Latin, Greek, math operators and arrows) converted to WOFF2.

| Open Sans | `OpenSans*.ttf` | The Open Sans Project Authors, https://github.com/googlefonts/opensans |
| STIX Two Text, STIX Two Math | `STIXTwo*.woff2` | The STIX Fonts Project Authors, https://github.com/stipub/stixfonts |
